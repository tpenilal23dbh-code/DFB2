# DFB (Digital Force Bag)

Web app instalable. Esta versión ha sido creada por Telmo.

## Subirla a GitHub Pages
1. Crea un repositorio nuevo en GitHub (por ejemplo `dfb`).
2. Sube **todo el contenido de esta carpeta** manteniendo la carpeta `icons/` (`index.html`, `manifest.webmanifest`, `sw.js`, `icons/`).
3. En el repositorio: **Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save**.
4. En un minuto tendrás la dirección `https://TU-USUARIO.github.io/dfb/`.

## Instalarla en el móvil
- **iPhone (Safari):** abre la dirección → botón Compartir → **Añadir a pantalla de inicio**. Ábrela siempre desde ese icono: así va a pantalla completa y se ve la barra de estado real de tu móvil.
- **Android (Chrome):** abre la dirección → menú ⋮ → **Instalar aplicación**.

## Para actualizar
Sustituye `index.html` en GitHub y abre la app con conexión una vez. Si no se actualiza, cambia `dfb-v1` por `dfb-v2` en `sw.js`.
